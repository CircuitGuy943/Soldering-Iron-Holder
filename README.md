Two simple, sturdy and easy to print soldering iron holders (no supports) designed to accomodate a metal scourer for cleaning the iron tip and storage spots for holder rolls, tweezers and extra iron tips.

One of the models is a free standing base for any desk fits needs. The second model is an re-designed version that allows you to clamp it with a desk grommet (the plastic thing that sits in a cable hole in desks) if you find the first model too slippy and want to anchor it to your table. *.f3d* files and *.step* files can be found in *3D Files* folder under the respective model directories. I hope you find these models useful!
